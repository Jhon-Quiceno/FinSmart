# Expo SDK 54

Este proyecto está fijado al SDK 54 (la versión que soporta Expo Go publicado en las stores —
ver docs/plan-app-movil-react-native.md §5.1 en la raíz del monorepo). Antes de escribir
código, leé la doc versionada exacta en https://docs.expo.dev/versions/v54.0.0/ — no asumas
APIs de versiones más nuevas.
